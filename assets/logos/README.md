# Эмблемы футбольных команд

Сюда складываем PNG-эмблемы команд. Имена файлов удобно задавать по ключу команды, например `zenit.png` или `real_madrid.png`.

Папка доступна контейнеру только для чтения как `/logos`. Перед использованием эмблему нужно зарегистрировать в постоянной медиабиблиотеке командой из `docs/OPERATIONS.md`; так сохраняются ключ, варианты названия команды и файл в Docker volume.
